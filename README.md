# 📝 To-Do App

A simple and user-friendly To-Do List application built with React and Vite.

The app helps users organize their daily tasks, track their progress, and easily manage completed and pending tasks.

# ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📋 View all tasks
* 🔄 Filter tasks by:
    * All
    * In Progress
    * Completed
* 🔢 Display the number of tasks in each category
* 📅 Organize tasks by date
* 💾 Save tasks using Local Storage
* 🌐 Arabic and English language support

## 📦 Installation

### 1. Clone the repository

 git clone https://github.com/Ahoodali/ToDo-App.git


### 2. Navigate to the project directory

cd ToDo-App


### 3. Install dependencies

``` npm install ```


### 4. Start the development server

``` npm run dev```
