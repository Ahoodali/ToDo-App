# 📝 To-Do App

A simple and user-friendly To-Do List application built with React and Vite.

The app helps users organize their daily tasks, track their progress, and easily manage completed and pending tasks.

# ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📋 View all tasks
* 🔄 Filter tasks by:
    * All
    * In Progress
    * Completed
* 🔢 Display the number of tasks in each category
* 📅 Organize tasks by date
* 💾 Save tasks using Local Storage
* 🌐 Arabic and English language support

# 🛠️ Technologies Used

* React
* TypeScript
* Vite
* HTML
* CSS
* JavaScript
* Local Storage

  # 🎨 Design & Development

* The initial UI design was created using a prompt in Figma.
* The design was then developed and customized using React, TypeScript, and Vite.
* Additional functionality and improvements were implemented during development.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone YOUR_REPOSITORY_URL ```

### 2. Navigate to the project folder
```bash
cd ToDo-App ```

### 3. Install dependencies
```bush
npm install ```

### 4. Start the development server
```bush
npm run dev ```

Then open the local URL shown in the terminal.
